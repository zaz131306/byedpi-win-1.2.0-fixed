Каталог synth/ — СГЕНЕРИРОВАННЫЕ файлы пула каналов.

В архиве здесь лежат только два файла:
  sources.txt   шаблон: СЮДА вписываешь СВОИ серверы (строки `own:метка vless://...`)
  README.txt    этот файл

Остальное создаст `SYNTH.bat` (или `python synth.py --lib4u`):
  mihomo.yaml     профиль Clash/Mihomo: эшелоны, fallback, DNS, DIRECT для RU-зон
  channels.txt    плоский список для Throne / v2rayN / Happ
  channels.json   состояние пула для orchestrate.py
  state.json      вердикт диспетчера

Пересобирай пул перед использованием: бесплатные подписки протухают за часы.
Описание архитектуры и честные ограничения — в ../SYNTH.md
